# Code of conduct

This project's issues, discussions and pull requests are a place to get work done together.

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Keep it on topic and specific — describe the problem, the steps and the version.
- No harassment, insults, discrimination or personal attacks, and no sharing of other people's private information.
- Do not post secrets, credentials or private code from your company or anyone else.

The maintainer may edit, hide or remove content and block accounts that break these rules.
To report a problem privately, use the contact on the maintainer's GitHub profile.
